1차 검수에서 발견해 수정한 문제

| 문제 | 수정 |
|---|---|
| 날짜 범위의 `~`가 마크다운 취소선으로 표시됨 | `–`로 교체 |
| 펼치기 아이콘이 `arrow_right` 글자로 표시됨 | 아이콘 폰트를 덮어쓰던 CSS 제외 |
| 반투명 막대 위 숫자 라벨이 잘 안 보임 | 불투명 막대 + 기준 브랜드 테두리로 변경 |
| 감성 차트의 x축 제목과 범례가 겹침 | x축 제목 제거, 단위를 차트 제목으로 이동 |
