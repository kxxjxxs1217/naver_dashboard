# 대시보드 UI·IX 평가 — 브랜드 톤앤매너와 보고 적합성

- 평가일: 2026-10-31
- 대상: `app/dashboard.py`
  - v2: 마케터 지표 고도화 버전
  - v3: 이번 UI·IX 개선 버전
- 관점: **브랜드 톤앤매너**(기준 브랜드의 색·서체·말투가 화면 전체에 일관되게 드러나는가)와 **보고 적합성**(그대로 캡처·인쇄·공유해 보고에 쓸 수 있는가)

  - **자동 검증:** Edge(headless) 1440px에서 3개 브랜드 × 2개 보기 모드 = 6개 화면을 열어 DOM을 측정했어요.

  - **내보내기·URL 검증:** 다운로드 파일을 실제로 받아 열어 봤고, 버튼을 누른 뒤 URL이 바뀌는지 확인했어요.
  - **화면 검수:** 대시보드 탭 6개를 전체 캡처해 육안으로 확인했어요.

## 남은 한계

- **대시보드 모드의 탭 이동:** Streamlit 탭은 코드로 전환할 수 없어서, 대시보드 모드의 경보는 탭 이름만 안내해요. 직접 이동은 보고서 모드에서만 돼요.
- **모바일 화면:** 768px 미만 화면은 이번에 검증하지 않았어요.
- **브랜드 서체:** Google Fonts에서 불러오므로 인터넷이 없으면 기본 서체로 보여요. 브랜드 톤앤매너도 분석에서 도출한 해석이고 각 사의 공식 가이드가 아니에요.
